# mdn-event-management

The app: Next.js frontend and API in one project.

Documentation lives in [`../docs/`](../docs). To get set up, read
[getting-started.md](../docs/getting-started.md); for where code belongs, read

```bash
npm test           # see ../docs/testing.md — the API tests need dev + Postgres
```
